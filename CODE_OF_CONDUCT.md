# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment or personal attacks, and keep
technical disagreement about the work. Maintainers may remove, edit, or reject contributions
and interactions that violate this standard.

Report conduct issues privately via GitHub (profile → report) or a repository security
advisory if sensitive. Reports are handled confidentially.
